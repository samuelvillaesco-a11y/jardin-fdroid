# Repositorio F-Droid de Jardín de Hábitos

Repositorio compatible con la app [F-Droid](https://f-droid.org/) (y con Droid-ify, Neo Store o F-Droid Basic) para instalar y actualizar **[Jardín de Hábitos](https://github.com/samuelvillaesco-a11y/JardinDeHabitos)**: deja un mal hábito cuidando un jardín privado. Sin internet, sin cuentas.

## Agregarlo

En el teléfono, abre este enlace (se abre F-Droid y te pregunta si quieres agregar el repositorio):

**[Agregar a F-Droid](https://fdroid.link/#https://samuelvillaesco-a11y.github.io/jardin-fdroid/repo?fingerprint=E3DDD5419D3C0CA7F79BC898A5368E2B015B164493F84846A09DE86A890FE92F)**

O en F-Droid: *Ajustes › Repositorios › +* y pega:

```
https://samuelvillaesco-a11y.github.io/jardin-fdroid/repo?fingerprint=E3DDD5419D3C0CA7F79BC898A5368E2B015B164493F84846A09DE86A890FE92F
```

Después busca "Jardín de Hábitos" e instálala.
